Préparer le dossier avant le formulaire

Le client choisit le type de compte, prépare les documents requis, puis le système effectue une première lecture OCR. Les informations détectées sont préchargées dans le formulaire d’ouverture de compte.

1
Choisir le type de compte Compte personnel ou compte entreprise.
2
Importer ou photographier les documents Pièce d’identité, justificatifs, RIB ou documents entreprise.
3
OCR et préchargement Le système extrait les informations utiles sans afficher de texte technique.
4
Continuer vers le formulaire Les champs détectés sont préremplis dans le formulaire client.
